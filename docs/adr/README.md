## 什么时候该写 ADR

| 写 | 不写 |
|---|---|
| 引入/更换一个核心依赖或框架 | 升级小版本依赖 |
| 改变 crate 之间的依赖方向 | 改函数实现 |
| 改变数据模型的持久化语义 | 加字段 |
| 改变安全模型或信任边界 | 调常量 |
| 改变发布形态或平台支持矩阵 | 修 UI |
| 改变是否需要服务端 | 加日志 |

写 ADR 时请用 [CONTRIBUTING.md](../CONTRIBUTING.md) 里的模板。
